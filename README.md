<h2>📌 About My Project</h2>

<p>
  A simple countdown timer created with vanilla JavaScript, featuring a beautiful design, particle animations, and a music control play button.
</p>

<h2>🛠️ Build</h2>

<ul>
  <li>HTML5</li>
  <li>CSS3</li>
  <li>JavaScript</li>
  <li>Particles animation</li>
</ul>

<h2>🎁 Usage</h2>

<p>
  This application provides a real-time countdown to Christmas.
</p>

<p>
  It includes a falling snow effect powered by
  <a href="https://github.com/VincentGarreau/particles.js/" target="_blank">particles.js</a>.
</p>

<p>
  Users can enjoy festive music by clicking the <strong>Play</strong> button.
</p>

<p>
  The application is fully responsive and works seamlessly on all mobile devices.
</p>

<h2>⚙️ How to Use & Set Up</h2>

<ol>
  <li>Clone this repository:
    <pre>git clone https://github.com/Yulya-ko/Christmas-countdown.git</pre>
  </li>
  <li>Open the project folder on your computer.</li>
  <li>Launch <code>index.html</code> in your browser.</li>
  <li>Enjoy the countdown and music!</li>
</ol>

<h3>🔊 Optional: Change Background Music</h3>

<p>
  Replace the existing audio file in the <code>music/</code> folder with your own MP3 file and update the path in <code>script.js</code> if necessary.
</p>

<h3>❄️ Optional: Customize Snow Particles</h3>

<p>
  To adjust the snow effect, edit the <code>particles.json</code> file or configuration object in <code>script.js</code>. For full documentation, visit
  <a href="https://vincentgarreau.com/particles.js/" target="_blank">particles.js official site</a>.
</p>
